البدء السريع | QUICK START
================================================================================

1. انقر مرتين على ملف "start-ui.bat"
   Double-click "start-ui.bat"

2. ستفتح الواجهة في المتصفح تلقائيًا
   The interface will open in your browser automatically

3. اكتب أو الصق كود TSX في محرر الكود
   Write or paste TSX code in the editor

4. اضغط زر "توليد الفيديو"
   Click "توليد الفيديو" (Generate Video) button

================================================================================
متطلبات الكود | CODE REQUIREMENTS
================================================================================

يجب أن يحتوي كود TSX على:

1. تصدير compositionConfig:
   export const compositionConfig = {
     id: 'MyVideo',
     durationInSeconds: 5,
     fps: 30,
     width: 1080,
     height: 1920,
   };

2. تصدير المكون الرئيسي:
   export default MyComponent;

================================================================================
الفيديو الطويل (صوت + مشاهد) | LONG-FORM MODE
================================================================================

من تبويب "فيديو طويل (صوت + مشاهد)":
From the "Long-form" tab:

1. ارفع التعليق الصوتي (WAV / MP3 / M4A / MP4).
   Upload the narration audio.
2. اختر الدقة و FPS وطول المشهد وموديل التفريغ، ثم اضغط
   "تحليل الصوت وتقسيم المشاهد".
   Pick size, fps, scene length and whisper model, then click "Analyze".
3. الأداة تفرّغ الصوت (faster-whisper) وتقسمه إلى مشاهد، وتُنشئ لكل مشهد:
   - scenes/sNN.json  : توقيتات الجُمل والكلمات
   - scenes/sNN.tsx   : مكان لصق كود المشهد
   - prompts/sNN.md   : برومت جاهز للشات بوت
4. لكل مشهد: "نسخ البرومت" ← الصقه في الشات بوت ← الصق الكود ← "حفظ الكود".
5. "رندر المشهد" للمراجعة السريعة، ثم "رندر الفيلم كامل" مع الصوت.

Each scene is a standalone TSX component that exports:
   export const sceneConfig = { id, start, end, fps, width, height };
   export default SceneComponent;

المتطلبات | Requirements
- Python 3 مع حزمة faster-whisper (مرة واحدة):
    python -m pip install faster-whisper
- أول تحليل ينزّل موديل التفريغ داخل tools\models (small ≈ 500MB).
- ffmpeg/ffprobe لقراءة مدة الصوت (اختياري: تُقرأ من التفريغ بدلًا منه).

ملفات المشروع | Project files
- films/<الاسم>_<التاريخ>/film.json     : بيانات الفيلم والمشاهد
- films/<الاسم>_<التاريخ>/transcript.json: نص التفريغ الكامل
- films/<الاسم>_<التاريخ>/public/        : الصوت والأصول (staticFile)
- films/<الاسم>_<التاريخ>/renders/       : المخرجات (mp4 / png)

سطر الأوامر | CLI
  render-film.bat "films\FILM_FOLDER"            (فيلم كامل)
  render-film.bat "films\FILM_FOLDER" scene s01  (مشهد واحد)
  render-film.bat "films\FILM_FOLDER" still s01 3 (صورة عند الثانية 3)

استكشاف الأخطاء | TROUBLESHOOTING
================================================================================

"فشل في حفظ الملف":
  - تأكد من أن المجلد غير محمي للكتابة
  - Make sure the folder is not write-protected

"فشلت العملية":
  - تحقق من كود TSX للأخطاء
  - Check your TSX code for syntax errors
  - تأكد من تصدير compositionConfig

"لم يتم إنشاء ملف الفيديو":
  - قد تكون هناك مشكلة في الكود
  - راجع سجل الأخطاء في الواجهة

"EADDRINUSE" خطأ:
  - السيرفر شغال من قبل، أغلق النافذة الأولى وافتح تاني
  - Server is already running, close the first window and try again

في أول تشغيل:
  - سيتم تحميل متصفح Chromium (~150MB)
  - هذا التحميل لمرة واحدة فقط
