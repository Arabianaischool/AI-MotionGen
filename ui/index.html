الفيديو الطويل (صوت + مشاهد)

                    

                        
1. ارفع التعليق الصوتي ثم اضغط «تحليل الصوت وتقسيم المشاهد».

                        
2. لكل مشهد: زر «نسخ البرومت» ← الصقه في الشات بوت ← الصق الكود في «تحرير الكود» ← حفظ.

                        
3. «رندر المشهد» للمراجعة السريعة، ثم «رندر الفيلم كامل» لإخراج الفيديو النهائي مع الصوت.

                        
كل مشهد له ملف scenes/sNN.json فيه توقيتات الكلمات، وprompts/sNN.md فيه البرومت الجاهز.
